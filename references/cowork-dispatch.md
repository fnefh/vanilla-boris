# Cowork Dispatch

Source: howborisusesclaudecode.com (Mar 30 2026 thread; verbatim quote
from Boris).

> "I use Dispatch every day to catch up on Slack and emails, manage
> files, and do things on my laptop when I'm not at a computer."
> — @bcherny

Cowork Dispatch is the secure remote-control layer for Claude Desktop.
Unlike `/remote-control` (which spawns local sessions from a mobile
device), Dispatch lets a remote operator drive a Desktop-mode Claude
session through a secured channel. Use cases per the thread:

- **Catch-up on Slack while away from the laptop** — open the Slack MCP
  via Dispatch, summarize unread channels, draft replies.
- **Email triage** — same pattern with the Gmail/Apple-Mail MCP.
- **File management** — move/rename/archive files using the file system
  tools without opening the laptop.

This plugin **does not configure Cowork Dispatch.** It requires desktop
+ mobile setup. Documented here for completeness.

Pairs with: `references/recommended-mcps.md` (Slack, iMessage, etc.)
and `references/customization.md` (mobile/multi-device patterns).
